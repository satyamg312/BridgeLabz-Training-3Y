Responsive Design

Responsive web design allows a website to adapt to different screen sizes and devices. CSS Grid, Flexbox and Media Queries are commonly used to create responsive layouts.

A responsive website provides better readability and usability on desktops, tablets and mobile devices.

Cheat Sheet

Flexbox

Used for flexible one-dimensional layouts.

Grid

Used for two-dimensional layouts.

Media Query

Changes styles according to screen size.
